# Stealth Calculator Chat

A private messaging application disguised as a calculator interface for
added privacy.

## ✨ Features

-   🔐 Calculator lock screen
-   💬 Private chat interface
-   👥 Contacts
-   📞 Calls
-   📷 Status
-   🤖 AI Assistant (Gemini)
-   🛡️ Privacy-focused design

## 🛠 Tech Stack

-   React
-   TypeScript
-   Vite
-   Express
-   Google Gemini API

## 🚀 Getting Started

### Install

``` bash
npm install
```

### Configure

Create a `.env.local` file:

``` env
GEMINI_API_KEY=YOUR_API_KEY
```

### Run

``` bash
npm run dev
```

## ⚠️ Security

Never commit your `.env` or API keys to GitHub.
